# JavaScript Multiplication Table Generator

A beginner JavaScript project that generates a multiplication table based on the number and limit entered by the user.

## Features

- Enter any number to generate its multiplication table
- Enter a custom table limit (e.g., 10, 12, 20, or any value)
- Generate the table dynamically
- Display the result instantly on the webpage
- Simple and user-friendly interface

## Example

```text
Enter Number: 7
Enter Limit: 15

7 × 1 = 7
7 × 2 = 14
7 × 3 = 21
...
7 × 15 = 105
```

## Technologies Used

- HTML5
- CSS3
- JavaScript

## JavaScript Concepts Used

- Variables
- Functions
- User Input
- DOM Manipulation
- `for` Loop
- Arithmetic Operators
- Template Literals

## Purpose

This project was created to practice JavaScript user input, loops, DOM manipulation, and dynamically generating a multiplication table with a custom limit.
