# JavaScript Multiplication Table Generator

A beginner JavaScript project that generates a multiplication table based on the number entered by the user.

## Features

- Take a number from the user using an input field
- Generate the multiplication table dynamically
- Display the table from 1 to 10
- Generate a new table whenever the user enters another number
- Simple and user-friendly interface

## Example

If the user enters `5`, the output will be:

```text
5 × 1 = 5
5 × 2 = 10
5 × 3 = 15
5 × 4 = 20
5 × 5 = 25
5 × 6 = 30
5 × 7 = 35
5 × 8 = 40
5 × 9 = 45
5 × 10 = 50
```

## Technologies Used

- HTML5
- CSS3
- JavaScript

## JavaScript Concepts Used

- Variables
- Functions
- Input values
- DOM manipulation
- `for` loop
- Arithmetic operators
- Template literals

## Purpose

This project was created to practice taking input from a user, using JavaScript loops, and dynamically displaying a multiplication table on the webpage.
